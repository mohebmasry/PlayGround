## ماتنخدعش

A complete, offline-capable Arabic interactive narrative about digital recruitment pressure and blackmail. It is built with plain HTML, CSS, and JavaScript—no build step or external runtime dependencies.

### Run locally

```sh
python3 -m http.server 3002
```

Open <http://localhost:3002>. The service worker caches the game after the first visit so it can be played offline. For mobile testing, open the same address from a device on your local network. The optional web font needs internet access; the game falls back to local Arabic fonts without it.

The fictional story contains psychological pressure, isolation, threats to share private messages, and an ambiguous meeting request. The game avoids real extremist ideology, graphic violence, and actionable harmful instructions. It ends with practical, non-blaming safety guidance.
